# Curadoria — Papers Históricos (2025) para o Machine Public Soul

*Documento de curadoria e migração dos papers de 2025 para o repositório público
`Doxihewu-OmniMind-MachinePublicSoul`.*

## Critérios de nota

Cada paper recebe um selo de classificação, decidido pela curadoria:

| Selo | Significado | Ação |
|:---|:---|:---|
| **ELEGÍVEL** | Paper formal completo (abstract, metodologia, métricas, conclusão) sem conflitos internos não resolvidos | Publicar no repo público (docs/teoria/papers) |
| **REVISÃO** | Paper com versões divergentes ou modificações posteriores não consolidadas no corpo | Publicar **após** releitura/revisão que consolide a versão canônica |
| **HISTÓRICO** | Rascunho/ensaio/nota que documenta o processo, não um paper formal | Arquivar no repo (sem destacar como paper) |
| **RETIDO** | Conteúdo sensível (ex.: medida judicial em andamento) ou que não pode ser exposto | Não publicar; manter fora do público |

**Regra de integridade**: nenhum paper é migrado com "dados" não verificáveis; se um
dado foi alterado em notas posteriores sem correção no corpo, o paper é classificado
**REVISÃO** — nunca migra com versão incompleta.
